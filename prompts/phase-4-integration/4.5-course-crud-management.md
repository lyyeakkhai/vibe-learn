# Phase 4.5 Implementation Prompt: Course CRUD Protected Route & Database Sync

## 1. Goal
Implement a protected administrative route at `/admin/courses` that allows authenticated users to perform full CRUD operations (Create, Read, Update, Delete) on courses with live synchronization to the Supabase PostgreSQL database.

## 4. Decisions and Assumptions
- **Scope:** Restricted to course metadata (Title, Slug, Summary, Category, Level, Price, Instructor Name, Instructor Bio, Instructor Avatar, Cover Image URL, and Popular status) as decided with the user.
- **Route URL:** `/admin/courses`, wrapped with `<ProtectedRoute>`.
- **Navigation:** A "Manage Courses" link will appear in the top navigation bar and mobile drawer when the user is signed in.
- **UI Architecture:** Master Table view with quick metric cards, search/category filter, and an accessible modal form dialog for Create/Edit, plus a delete confirmation modal.
- **Images:** Image URL text input with quick preview and preset selectors using existing local course images.
- **Database Sync:** Direct mutations to Supabase `public.courses` using `supabase.from("courses")`.

## 6. Requirements
- Create course with auto-generated slug fallback if not provided.
- Real-time search filter and category filter.
- Update course preserving existing modules and lessons in Supabase.
- Delete course from Supabase and update state immediately.
- Fully responsive on mobile, tablet, and desktop.
- Dark mode support using semantic theme tokens (`bg-card`, `text-card-foreground`, `border-border`, `bg-primary`, etc.).

## 7. Security Considerations
- Route `/admin/courses` is strictly enclosed in `<ProtectedRoute>` so unauthenticated visitors cannot access or view the management interface.
- Deletions require explicit confirmation to avoid accidental data loss.
- Slugs are sanitized to prevent URL injection or malformed paths.

## 8. Acceptance Criteria
- Unauthenticated user navigating to `/admin/courses` is redirected to Clerk sign-in.
- Authenticated user can see all courses in a clean table with metrics.
- Clicking "+ New Course" opens modal; creating a course persists it to Supabase and adds it to the list.
- Clicking "Edit" allows changing title, price, category, level, etc., and updates in Supabase.
- Clicking "Delete" prompts confirmation and removes course from Supabase and table.
- Created/updated courses appear on the public `/courses` catalog page.
