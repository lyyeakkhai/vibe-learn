# Implementation Prompt: 4.7 - Cloudinary Image Storage Integration

## 1. Goal
Integrate Cloudinary image storage into Vibelearn to handle rich course and instructor media. Build a secure NestJS `MediaModule` with `POST /api/media/upload` that streams image buffers in memory directly to Cloudinary. In the frontend, create a reusable `ImageUploader` component with drag-and-drop, validation, instant previews, and an optional manual URL / preset fallback, and integrate it into `CourseFormModal` on the admin courses page.

## 4. Decisions and Assumptions
1. **Server-Side Upload Streaming**: All image uploads are routed through the NestJS backend to keep `CLOUDINARY_API_KEY` and `CLOUDINARY_API_SECRET` completely confidential.
2. **In-Memory Buffer Streaming**: Use Multer memory storage (`file.buffer`) and Cloudinary's `upload_stream` to prevent creating temporary files on server storage.
3. **Authentication Gating**: The media upload endpoint is protected with `ClerkAuthGuard`. Anonymous requests are rejected with `401 Unauthorized`.
4. **Folder Organization**: Assets are categorized into Cloudinary folders: `vibelearn/courses` for course covers and `vibelearn/instructors` for instructor avatars.
5. **File Limits & Validation**: Files are restricted to 5MB and must have image MIME types (`image/jpeg`, `image/png`, `image/webp`, `image/gif`, `image/svg+xml`).
6. **Backward Compatibility**: `CourseFormModal` maintains an expandable fallback to enter image URLs manually or pick presets, ensuring existing workflow flexibility.

## 6. Requirements
- **Server Security**: Zero exposure of Cloudinary API keys or secrets in the client bundle.
- **Memory Safety**: No disk writes or unmanaged temp files on the NestJS host.
- **Design System Consistency**: `ImageUploader` must follow the semantic tokens in `DESIGN.md` and `src/globals.css`.
- **Drag & Drop UX**: Clean upload zone with drag-and-drop, animated loading spinner, instant image preview, remove button, and error alerts.
- **Form Integration**: Disable modal submit during active uploads to prevent race conditions.

---

## 7. Security Considerations
- Require authenticated Clerk bearer token for `POST /api/media/upload`.
- Validate file size and MIME type both client-side and server-side.
- Cloudinary credentials must be injected solely via `@nestjs/config` `ConfigService`.
